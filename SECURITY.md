# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Devnet.Vault, please do **not** open a public issue.

Instead, contact the maintainers directly and provide a clear description of the issue, the affected area, and any reproduction steps.

## What to include

- Summary of the vulnerability
- Steps to reproduce
- Expected behavior
- Impact assessment
- Suggested fix, if you have one

## Response expectations

We will review reports as soon as possible and work with the reporter on a fix.

## Responsible disclosure

Please avoid public disclosure until a fix has been released or a maintainer has confirmed the issue is handled.
